# Digger Money Trail

Tests whether who owns a film critic's outlet predicts how they scored *Digger* (2026).

- `site/index.html` – the interactive page (published as a claude.ai artifact)
- `data/` – Metacritic reviews, baseline films, ownership chains, analysis output, research notes
- `data/rt/` – Rotten Tomatoes critic reviews collected from the browser
- `scripts/` – analysis pipeline (`baseline.py` → `analyze.py` → `bundle.py`) and `rt_console_resume.js`
